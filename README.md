# SSK Fasteners

Website: https://sesathishkumar.github.io/ssk-fasteners/

A responsive business website for M6–M12 bolts and nuts in Chennai, with the official SSK Fasteners logo, product information, buying guide, and phone, WhatsApp, map and email links.

## Hosting and updates

GitHub Pages publishes from `main` at `/ (root)`. The published runtime files are `index.html`, `styles.css`, `app.js`, `fasteners.jpg` and `logo.png`. Upload changed files to the root and commit to update the website.

In the local project, these files are in `dist/`. Run `node server.mjs` locally to preview at http://127.0.0.1:4173.

## Enquiries

The form prepares a draft addressed to sskfasteners@gmail.com in the visitor’s email application. The visitor reviews and sends it. The website has no server-side form inbox, analytics, cookies or external fonts. Phone and WhatsApp links provide alternative contact methods.
